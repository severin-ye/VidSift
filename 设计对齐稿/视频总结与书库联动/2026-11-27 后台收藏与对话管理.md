# 后台收藏与对话管理

用户确认收藏沿用普通的 ChatGPT 总结流程，生成时留在后台，避免打断手头操作。两处移除只处理书库中的所选记录，保留账号里的 ChatGPT 对话和已有批注。

## 使用方式

- 视频页打开知行视频总结，和原发送按钮并列提供「收藏」。收藏复用现有字幕、音频、图片、提示词和任务队列，生成普通的私人 ChatGPT 对话。
- 收藏等待本次请求产生正文并由书库确认记录。成功后自动关闭扩展为收藏创建且用户未激活、仍停在本次对话的 GPT 标签页。失败、待验证或未确认入库时保留需要处理的页面。
- 视频页和已收录的 GPT 总结页通过同一个弹窗查看同视频的书库对话。视频页打开新标签以便保留原视频，在 GPT 页沿用当前标签切换。视频页的已完成总结提醒继续单独核验生成状态。
- 移除前显示对话时间和影响范围。书库在同一个事务中核对视频、分 P 和所选对话，再移除记录。GPT 页移除当前对话后如有其他成员则切换，移除最后一项时原 GPT 页面仍可阅读。

## 与既有数据的关系

书库仍保存视频、封面与可回访的私人对话链接。收藏不需要新增 OpenAI API 或书库正文存储。复用书库的单条移除、数据同步和主对话回退。老版本书库可以列出和打开对话，移除需要支持新协议的版本。

## 验收边界

隔离浏览器使用合成视频和 GPT 返回，通过两个扩展的真实消息、标签和书库存储验收。实际 Chrome 和 Edge 的安装、重载及真实站点生成单独记录。
