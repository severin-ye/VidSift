- 状态：用户目标已明确授权；以下实现方式由 Agent 选择，安装与真实 ChatGPT 验收分别记录，不冒充用户逐项确认。
- 与现状关系：复用现有后台任务、来源保护、目标回执和书库状态；本地推理队列仅管理推理，本次队列管理 ChatGPT 总结，不替代书库入库队列。

- 来源仍存在但切换作品时维持原取消保护；手动取消和目标页关闭仍生效，不将关闭浏览器或重新加载扩展纳入继续承诺。
- 多个视频从接单开始排队，材料获取、Groq转写和 ChatGPT 总结依次处理；等待本次 user message 的后代 assistant 回复成功结束，不能用会话标题或旧回复释放队列。
- 普通会话复用已有对话身份与消息匹配；临时聊天不保存书库，通过新目标页助手回复及停止生成控件确认稳定结束。
- 访问验证在原目标页等待，人工完成后自动继续；已发送后发生改名、书库、鉴权、超时等问题不自动重发总结。
- 队列仅属于本次扩展运行，保活覆盖排队和目标等待；退出浏览器、扩展重载、更新或工作进程异常终止不承诺恢复，不新增离线重发。
- 隐式状态审查：已接收→材料获取→等待发送→目标连接/访问验证→附件发送→本次生成等待→成功或失败；取消/目标关闭/超时均释放当前项，迟到回执须同时匹配任务 ID 和目标标签 ID。
- 验证：源页获取前/转写中/上传中关闭、源切换/手动取消、API错误分类、重复点击、排队取消与推进由定向测试覆盖；隔离 Edge 使用模拟 B站与 ChatGPT API 验证两个源页立即关闭、旧标题不提前释放、各发送一次、生成后推进。真实站点另行验收。
