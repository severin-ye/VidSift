# Groq密钥输入与原任务继续

- 来源：用户2026-11-11要求在需要音频转写但未配置API时弹窗输入，并提供申请网址按钮；产品目标已明确，具体安全保存和任务衔接由Agent实现。
- 现状：抖音缺省Groq，Native读取环境变量或个人`.env`；没有密钥时到上传阶段报错，设置页只能检测存在性。
- 复用现有“抖音转写”，补充配置入口，不新增独立功能模块；有字幕直接GPT、其他转写选择与提示词、书库、临时聊天边界保持。
- 实际需要Groq转写时检测密钥；缺失则打开扩展自己的独立小窗口，含密码输入框、“保存并继续”、“取消”和下方小号“申请Groq API Key”按钮；申请按钮只打开https://console.groq.com/keys，不自动注册、开通付费或填入密钥。
- 输入只经可信扩展页及Native Messaging传给本机程序；Native固定Groq模型列表接口验证鉴权，成功后Windows当前用户DPAPI加密、原子保存到共享runtime/credentials，不写浏览器storage、网址、日志、安装包或命令行。
- 保留环境变量与原`.env`优先；新加密存储只作为缺失时的后备。已有配置不被覆盖，不自动迁移私密内容；设置页提供相同入口，检测仍只返回存在性。
- 成功后先重新核对源作品/取消状态，再继续原音轨、原任务，只转写与发送一次；无效密钥在原窗口说明并允许更正，关闭窗口或取消不继续上传、发送。
- 每个任务只保留一个带随机令牌的窗口；消息必须来自该窗口及固定扩展URL，跨网站、其他扩展页、过期令牌均拒绝。等待有界，任务取消/来源切换与窗口关闭清理等待状态。
- 验收：缺失/已有、错误/网络失败、申请链接、关闭/取消、来源改变、重复保存、成功恢复、秘密不进存储/诊断、DPAPI写入与旧状态保护；隔离浏览器不使用日常配置，真实安装保留回退。

## 实施计划

1. Native凭据校验和DPAPI存储及隔离测试；固定动作groq_store_key({apiKey})，只返回configured。
2. 扩展窗口及可信消息/取消生命周期；在现有Groq转写之前等待配置，NativeClient增加保存入口。
3. 相关Node/Native与隔离浏览器回归，更新说明与版本，打包、备份安装并核对日常加载；提交/主线整合/发布/父指针核验。

## 兼容边界

- Windows DPAPI密文仅当前Windows用户可读，其他系统不降级成明文。
- 旧Native5.4不认识新加密保存；回退时原环境变量/.env仍有效，新加密文件保留，旧版新用户需自行配置.env，不删除密钥。
- 本任务测试资源放在私有.task-artifacts/key-prompt，原始输入不含真实密钥；隔离浏览器profile和测试凭据目录在退出后清理，保留日志、截图和回执。
