# 已有总结提醒：已确认方案与实施

## 已确认的用户要求

- 展开采用首轮第1种白色“简洁通知”；折叠入口采用第二轮第1种“文字胶囊”。
- 默认只显示折叠入口，点击后列出同一视频的全部已核实完成总结，每份单独打开对应对话。
- 用户补充：“把那个视频放大的时候……它得隐藏这个”；实施覆盖原生全屏、网页全屏、影院状态和当前视频占据窗口的放大观看。
- 退出放大观看只恢复折叠胶囊，不重新弹出旧列表；普通尺寸开始播放不额外隐藏。
- 用户在问答卡明确选择“只列出核实已生成完成的总结，需要增加完成状态核验”；已保存对话、生成中、空答复和未知结果不能计入已完成数量。
- 来源：本聊天 `01a1d296-6c3c-7a13-922f-530dcc09c09a` 的三轮选择，以及实施轮 `01a1d2b5-7d3c-7211-b5ee-fe16a404a1b3` 的问答回执；前两轮候选保留作历史来源。

## 与现状的核对和职责

- 已复核[原有视频入库边界](../视频总结与书库联动/2026-11-10%20视频总结自动入库.md)、现行 `video-library.js`、`background-library.js`、`chatgpt-content.js`、`platform-content.js` 和书库 `src/background/video_library.ts`、`src/shared/video_library.ts`。
- 原有书库只保存元信息，不存在生成完成字段；本轮不改写原记录、不建立第二个书库，也不把发送或保存回执升级为生成完成。
- 书库在原白名单外部协议增加 `list-video-v1` 只读分页能力；只读当前浏览器持久投影，返回轻量标题、身份、链接和时间。
- VidSift 仅查询当前视频对应的保存记录，再通过已登录 ChatGPT 的只读会话接口核实正式答复；不检索全部聊天历史，不新建或重发总结，不保存正文和凭据。
- 完成证据要求对话身份一致、对应初始用户请求有非空的 assistant 正式答复，且 `finished_successfully + end_turn`；思考内容、其他请求的旧回复不能作为证据；此检验不评价总结事实或质量。
- B站按 BV 和分P匹配；同 BV 不同P不会混入；不同 ChatGPT 对话独立保留。
- 读取失败与未知不冒充零条；旧书库不支持查询时提示更新。已完成计数只针对已核验结果，多页时明确显示核验进度并提供继续核验入口。
- 读取后再核对书库快照，删除或列表变化会丢弃旧结果；游标失效有且仅有一次自动重启，之后保留可操作错误。
- 临时聊天不入库、原删除 tombstone、封面待办、评分及日期功能均保留；本轮不改变 Native 或数据中心存储协议。

## 界面与恢复

- 文字胶囊和白色列表在 VidSift 自有 Shadow DOM 内，避免改写站点正文；位置为右上角。
- 进入放大观看会隐藏整个 host 并清除展开状态；退出只出现胶囊，即使查询期间刚返回结果也不自动展开。
- 手动刷新核验保持当前面板展开；切换视频、退出放大和重新进入页面都使用默认折叠。
- 两份记录默认同时可见，较多记录在列表内滚动并显式继续核验，不静默截断为“全部”。
- 设置复用书库联动块，增加“已有总结提醒·开 / 已有总结提醒·关”；恢复该块默认不删除记录、待办或覆盖其他设置。
- 没有可用普通 ChatGPT 页时，会临时创建一个不切换焦点的核验页；只清理本任务创建且从未被用户接管的页，用户曾激活或改变用途后保留。

## 状态流与异步审查

| 对象 | 状态及转换 | 保护与验证 |
|---|---|---|
| 页面查询 | 未查询 → 查询/核验 → 已完成结果、生成中、未知、错误 | 源身份和epoch隔离，切源丢弃迟到结果；失败不记为零 |
| 提醒 | 默认折叠 ↔ 手动展开；观看模式 → 全部隐藏 → 退出后折叠 | 全屏事件、平台状态属性和可见视频几何，观察器不触发循环网络请求 |
| 记录分页 | 本地投影快照 → 有版本签名的后续页 | 匹配集合变化回LIST_CHANGED，只重启一次；核验后复读防旧删除记录重新出现 |
| ChatGPT回复 | 待生成/未知 → 对应请求的完成且非空正式回复 | 不采用标题或任意旧回复，不保存原文；账户不可读则明确未知 |
| 临时核验页 | 创建/共享借用 → 引用归零 → closing → 清理结束 | closing期间不能重新借用；失败和正常清理共用“从未被用户接管”保护 |
| 切源取消 | 活跃 → 源变化/标签关闭 → 取消未开始请求 | 全局最多2个会话核验；取消排队后不再新增读取；已有请求有超时并忽略结果 |

审查发现并已修复：核验页曾只按清理瞬间状态判断、失败路径无条件关闭，以及关闭过程可能被新请求重新借用；均有先失败后通过的定向回归。联调发现的手动刷新意外折叠和SPA首个旧视频遮蔽检测也已修正。必要检查以最终版本证据为准，不把设计表当作程序保证。

## 资源和验收边界

- 事件只触发当前视频查询，合并同标签同查询的进行中请求，不新增常驻服务或高频网络轮询；DOM/全屏事件只更新显示。
- 书库一次最多10条候选进入核验；跨所有活跃请求最多2个会话读取，每次API有8秒期限，单条消息18秒超时；旧请求取消并丢弃结果。
- 核验正文只在 ChatGPT 页内存短暂读取，最大6MiB及10000个映射节点，超限报告未知，不返回正文或token。
- 整合时书库主线已从3.9.0更新至3.10.0并安装评分/日期；本候选先合入该主线，目标版本为书库3.11.0、VidSift5.9.0，禁止降级覆盖。
- 已完成的证据包括纯逻辑、协议和两个真实MV3扩展的隔离浏览器联调；联调API及平台页面为合成数据，只有浏览器全屏API为真实交互。
- 源码、构建、安装文件、浏览器实际加载及真实已登录ChatGPT核验分别记录在本任务 `.agent-status/existing-summary-design-1113.md`，不互相替代。
- 本轮没有修改 Severin-skill 仓库的正式模块；其功能目录不需新增 VidSift 产品条目。VidSift 和书库各自 README、原设计、协议及本说明维护实际边界。
