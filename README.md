- 取消立即停止本机网络进程并丢弃晚结果，不能保证Groq服务器已开始的计算停止；错误只记录脱敏类别。
- 已完成本地Whisper候选及固定模型缓存仍保留为显式可选路径，使用Groq不加载本地模型；[本地模型实测](docs/中文模型对比-2026-11-10.md)作为历史比较。

## 内容处理

- 5.2.4修复Windows本机程序启动子Python时继承浏览器消息输入导致阻塞的问题；需要更新Native，复用已有FFmpeg和依赖缓存，不安装转写模型。
- 扩展弹窗打开、点击运行及后续提取/上传/转写/发送阶段自动留存本地诊断；最多20条任务，每任务120条事件，并有总量限制。
- 诊断包含版本、作品编号、阶段、耗时、失败/取消分类及附件DOM结构摘要；不保存完整网址、账号、令牌、提示词、字幕正文或音频，也不自动上传日志。
- 本机调用阻塞已有真实Windows协议与实链对照证据；抖音AI Studio发送仍需用本次新日志确认具体停止阶段，不能把模拟通过称为实站恢复。

| 平台 | 实现路径 | 现有实站证据 |
|---|---|---|
| B站 | 保留原字幕接口、独立音轨、多分P与稍后再看；开启图片时调用本机程序 | 用户反馈Edge初步正常；完整回归尚未全部完成 |
| YouTube | youtube-transcript-api 字幕，yt-dlp 字幕/媒体回退 | 已取得61段字幕、完整音轨、19秒视频拼图；目标网站上传尚待验收 |
| 抖音 | 优先从当前播放页取得同作品独立音轨；没有或失败时回退原视频，图片开启时下载视频 | 完整独立音轨与原视频声音采样对照通过，用户确认上传成功；本次自动发送修复仍待登录页面验证 |

- 优先使用已有字幕，中文优先；抖音无字幕默认Groq云端Whisper，其他平台保留原有AI Studio、浏览器Whisper或自建转写选择。
- 浏览器内 Whisper 和自建服务输出 SRT 发送至 ChatGPT；AI Studio 在后台接收音频并生成完整SRT，确认完成后自动交给ChatGPT整理。
- YouTube、抖音和图片处理需要本机程序；本机程序负责媒体处理及固定模型文件的共享缓存，模型推理在浏览器执行，不安装本机ASR服务。

- 视频页不显示进度浮窗，关闭扩展弹窗后任务继续，视频页或本任务AI Studio/ChatGPT页重新打开扩展均可查看进度和取消。
- AI Studio连接依据上传脚本握手，不等待无关图片等整页资源结束；明确检查页面接收任务的应答，失败不盲目重复上传。
- 仅在本地保存最近一次目标页交接阶段、版本、任务ID和活动状态用于排障，不保存音频、提示词或账号凭据。
- 取消时显示具体原因；抖音来源变化消息需与标签页当前网址复核，旧消息不能取消当前仍匹配的作品；仅切换焦点不取消任务。
- AI Studio始终后台打开；只有完整逐字稿通过格式与完成标记校验才交给ChatGPT，生成失败/取消/来源切换均不交接；AI Studio页保留用于检查失败材料。

## 提示词

- AI Studio默认输出完整、带绝对时间戳的SRT逐字稿，不再要求隐藏字幕或只输出总结；长音频若无法完整输出，必须说明停止位置。
- ChatGPT内置默认采用用户保存的《视频深度理解与结构化总结提示词》，保留关键知识和论证逻辑；已有自定义提示词仍优先使用，恢复默认只影响该提示词块。
- 5.1.0需同时更新本机程序，以应用音频设置；安装器复用FFmpeg与下载缓存，不新增转写模型。

## 音频大小与后台打开

- 设置页可单独保存/恢复音频参数，默认AAC 64 kbps、单声道，来源音轨目标64 kbps；优先保留完整口播和原声语言。
- 平台有多种完整音轨时优先选择较小来源；只有单一完整音轨时，压缩只能减少上传大小，不能声称下载量同步减少。
- 本机压缩检查全长，默认不变更采样率；原B站浏览器音轨流程继续选最小带宽，不强制改走本机。
- 同一821秒抖音样本由13,545,027字节压为6,799,130字节，时长差小于0.01秒；尚未比较转写准确率。
- “GPT后台打开”只控制最终GPT页面是否切到前台；AI Studio转写阶段始终后台打开，关闭弹窗后任务仍继续。
- 附件采用分块传输后一次提交，避免抖音现代路径重复携带base64音频并超过浏览器64 MiB消息限制；旧目标页脚本会提示重新从视频页发起。
- 隔离Edge已验证27/60 MiB附件逐字节一致和单次上传/Run；实际登录AI Studio与GPT接力仍待验收。

## 图片设置

- 图片提取默认关闭；关闭时不为截图下载视频或抽帧，无字幕时仍可能下载必要音频或抖音原视频。
- 开启后默认按场景变化选帧，不能理解画面语义；无有效候选或检测失败时回退到间隔截图。
- 默认间隔5秒、每张3×3、最多15张最终拼图，即最多135个画面；每格带时间戳，末张可不足九格。
- 超出容量时自动增大间隔以覆盖全程；截图设置块可独立保存和恢复默认。
- SRT/音频及所有拼图确认上传成功后才自动发送；未知上传状态不会重新上传，失败会报告具体附件。

## 错误日志与 CLI 排查

- 扩展显示的错误会自动保存为本地诊断，Agent可直接读取，不需要用户复制控制台文字；记录时间、版本、组件、可关联任务、具体原因及脱敏提示，不上传到开发者服务器。
- 使用 `python scripts/diagnostics.py --json` 自动查找本机 Edge / Chrome 的独立扩展诊断；`--store <Local Extension Settings/扩展ID>` 指定配置，`--since 2026-11-10T00:00:00+09:00 --limit 50` 限定时间和条数。
- CLI 不打开浏览器、不写数据库，能读取滚动日志及压缩后的表；损坏、持续变化或缺少文件时返回退出码2并明确报告不完整，不把部分结果称为全部历史。
- 总结发送、对话确认、书库保存和会话改名是不同阶段；入库失败会保留待办，重试不会重新发送总结；“重试保存与改名”仍需校验本次实际捕获的会话和消息身份。
- 错误日志最多500条、约512KB，独立于最近20个任务的阶段日志；断连兜底另有总量上限，旧版没有记录的信息不能补造。
