## 抖音云端转写

- 有同作品字幕时直接使用；没有可用字幕时默认Groq Whisper large-v3-turbo，完成后发送SRT和原有自定义提示词到GPT，B站/YouTube选择保留。
- 同一5分钟完整音轨实测large-v3为3.704秒、turbo为2.005秒；生产Native另测5分钟2.578秒、33分钟32.813秒（含全长压缩与上传，不含下载和GPT生成），不是网页全流程耗时。
- 两模型均保留主要论点与数字，仍有专名和同音误字；实测依据与限制见[Groq中文转写对比](docs/Groq中文转写实测-2026-11-11.md)，不宣称逐字准确。
- 需要Groq音频转写但未配置密钥时，自动弹出密码输入窗口，底部“申请Groq API Key”打开[官方申请页面](https://console.groq.com/keys)；验证并保存后继续同一任务，有现成字幕时不弹窗。
- 输入值仅经扩展自己的可信窗口传给Native，验证成功后由Windows当前用户DPAPI加密保存在共享本机目录，不进入浏览器storage、日志、网址、命令行或安装包；需Native5.5.0。
- 已有环境变量与个人`.env`的`GROQ_API_KEY`优先且不覆盖，设置页可检测存在性或打开同一填写入口；无效密钥在原窗口更正，取消或切换视频后不继续转写、发送。
- “抖音转写”设置可单独保存或恢复本块；提供模型、30–600秒请求超时、媒体时长/大小及缓存限制，恢复保留其他块与草稿。
- 上传保守上限24MB，较大音轨先全长压缩为AAC64k单声道，仍超限会明确停止；不截断、不自动重试、不切换收费或其他云端服务。
- 取消立即停止本机网络进程并丢弃晚结果，不能保证Groq服务器已开始的计算停止；错误只记录脱敏类别。
- 已完成本地Whisper候选及固定模型缓存仍保留为显式可选路径，使用Groq不加载本地模型；[本地模型实测](docs/中文模型对比-2026-11-10.md)作为历史比较。
- 默认媒体限制60分钟/512MiB、缓存1GiB，失败24小时/成功1小时；失败重试先核验并复用原音轨，图片默认关闭。

- 历史5.4.1日常Edge已验证42分钟抖音视频的Groq→GPT非空总结与普通书库关联，点击后约56.5秒完成发送；新密钥弹窗验收独立记录，不把既有密钥成功当成新输入保存验收；当前候选版本以package.json与清单为准。
- 普通视频总结会话按“【平台】＋清理后的原视频标题”自动改名，平台为抖音、B站或YouTube；去除重复平台前缀、尾部话题标签和@提及，保留原题正文与标点；书库原题、字幕文件名及历史会话不批量修改，临时聊天不改名。
- GPT长时间思考时保留改名等待，最长15分钟后标记待改名；只重试原会话的改名，不重复发送字幕。

## 已归档功能

- 总结伴播已按用户要求取消，运行入口与代码已撤回；原实现及探针保留在[Git归档](https://github.com/severin-ye/VidSift/tree/codex/archive-summary-companion-20261113/archive/summary-companion-20261113)，不作为可用功能。

## 为什么做这个扩展

- 看完一段课程、访谈或演示后，想留下可回看的笔记，往往还要手动找字幕、转写音频、截取画面，再把材料交给 AI。
- 知行视频总结把这些步骤串在一起，让你从视频页面发起一次任务，再到 ChatGPT 查看整理结果。

```text
有字幕的视频 → 提取字幕 → ChatGPT 整理
无字幕的视频 → 获取音频 → 转写为 SRT → ChatGPT 整理
需要参考画面 → 开启图片提取 → 带时间戳的拼图随内容上传
```

- 例如，整理一段没有字幕的课程时，抖音默认先由Groq生成完整逐字稿，其他平台按所选服务转写，再交给 ChatGPT 按你的提示词整理知识点和论证关系。
- 你可以分别修改转写和总结提示词，笔记的准确性与完整性仍需要对照原视频核查。

## 能做什么

| 功能 | 使用方式与边界 |
|---|---|
| 字幕优先 | 优先使用平台已有字幕，中文优先，减少不必要的下载和转写。 |
| 无字幕转写 | 抖音缺省Groq；同时保留AI Studio、本地Whisper与自建服务，其他平台沿用原选择。 |
| 视频画面辅助 | 可提取带时间戳的画面拼图，与文字一起上传，图片提取默认关闭。 |
| 自定义提示词 | 可分别设置 ChatGPT 和 AI Studio 提示词，已有自定义内容优先于默认值。 |
| 后台处理 | 关闭扩展弹窗后任务继续，重新打开弹窗可查看进度或取消。 |
| 自动上传与发送 | 确认本次附件全部上传成功后自动发送，状态不明时停止，避免盲目重复上传。 |
| 书库联动 | 普通聊天可将视频链接、封面副本和私人 ChatGPT 对话链接保存到知行批注书库，需要兼容的书库扩展与 Native 数据中心。 |
| 独立设置 | 可与原版 B站总结扩展并存，两个扩展的设置和模型缓存分别保存。 |

### 内容如何到达 ChatGPT

```text
视频 → 优先提取已有字幕 ─────────────────────────┐
         │                                      │
         └─ 无字幕 → 获取音频 → 转写为 SRT ──────┤
                               │                │
                               ├─ Groq / AI Studio │
                               ├─ 本地 Whisper  │
                               └─ 自建服务      │
                                                ↓
                               ChatGPT + 自定义提示词 → 整理笔记

图片提取·开 → 提取视频画面 → 带时间戳的拼图 → 随内容上传
```

- 例如，整理一段没有字幕的课程视频时，抖音默认流程会把音频交给Groq，其他平台按原转写设置处理，待完整 SRT 逐字稿通过校验后，再自动交给 ChatGPT 整理。
- AI Studio 输出被截断、转写失败或任务被取消时，扩展不会继续交接，并保留 AI Studio 页面供检查。
- 最终笔记由 AI 服务生成，内容完整性与准确性仍需要对照原视频核查。

## 支持范围与当前状态

| 来源 | 已实现的处理方式 | 现有验证与限制 |
|---|---|---|
| B站 | 字幕、独立音轨、多分 P、稍后再看，以及可选画面拼图。 | 已有 Edge 初步正常的用户反馈，完整回归尚未全部完成。 |
| YouTube | 通过本机程序提取字幕，必要时回退到媒体下载和音频处理。 | 已验证字幕、完整音轨和短视频拼图提取，已通过用户真实YouTube字幕→GPT总结；其他样本与完整回归仍有边界。 |

## 快速开始

### 1. 下载、解压并加载

1. 打开[最新版下载页](https://github.com/severin-ye/VidSift/releases)，在最新一条发布记录的 **Assets** 中下载 `VidSift-版本号-standalone.zip`。
2. 将 ZIP 全部解压到固定文件夹，确认其中能看到 `manifest.json`，不要只在压缩软件内打开。
3. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择上一步包含 `manifest.json` 的文件夹，按浏览器提示确认权限。
5. 核对名称为“知行视频总结”，再将它固定到工具栏。

- 发布页的 `Source code (zip)` / `Source code (tar.gz)` 是开发源码，请选择上面有完整文件名的扩展安装包。
- 浏览器需要加载解压后的文件夹，不能把 ZIP 当作商店安装按钮直接打开，加载后也不要删除或移动该文件夹。
- 普通用户不需要运行 Git、`npm ci` 或构建命令，下面只有使用部分媒体功能时才需要额外安装本机程序。
- 扩展 ID 为 `kggdkncbamdlhhihfkeldbbkppkgihad`，可以保留原版扩展，无需卸载。
- 更新时将新版解压到原加载目录并在扩展管理页点击“重新加载”，随后刷新视频页和目标网页，保留浏览器设置与原有数据。

### 2. 按需安装本机程序

- **YouTube、抖音和图片提取需要本机程序**，只处理 B站已有字幕时可以先跳过此步。
- Windows 安装需要先安装 `uv`，并使用系统自带的 .NET Framework C# 编译器，前提与回退方法见 [INSTALL.md](INSTALL.md)。
- 在 VidSift 文件夹打开 PowerShell，执行：

```powershell
.\installer\Install-NativeHost.ps1 -ProjectRoot (Get-Location).Path -Version (Get-Content .\package.json -Raw | ConvertFrom-Json).version
```

- 安装器会在 `%LOCALAPPDATA%\VidSift` 创建 Python 3.12 环境，安装媒体依赖，并注册 Chrome / Edge 的 Native Messaging 主机。
- 本机程序使用 yt-dlp、FFmpeg、youtube-transcript-api 和 Pillow 处理媒体，不会额外安装转写模型，也不是常驻 HTTP 服务。
- 安装完成后，在设置页点击“检测本机提取程序”，确认连接成功。
- macOS / Linux 暂无随项目提供的对应安装流程。

### 3. 开始第一次总结

1. 登录ChatGPT；抖音Groq路径先按安装说明配置本机密钥，选择AI Studio时另需登录Google AI Studio。
2. 打开扩展“设置”，选择转写方式并检查两组提示词。
3. 返回视频页，先保持“图片提取·关”，点击弹窗中的提取或发送按钮。
4. 等待内容提取、必要的转写和附件上传完成，在 ChatGPT 中查看整理结果。

- **点击运行会触发自动上传和发送**，请先确认视频内容适合交给所选服务处理。
- 按钮文字会随字幕状态和转写方式变化，任务开始后可以关闭弹窗。

## 使用方式

### 选择转写方式

| 方式 | 音频在哪里处理 | 需要准备什么 |
|---|---|---|
| Groq（抖音缺省） | Native读取本机密钥并上传完整音轨，生成带时间戳SRT后交GPT。 | Native5.4.0及以上、本机GROQ_API_KEY和网络访问；默认turbo，可选择large-v3。 |
| AI Studio（其他平台原默认） | 上传至 AI Studio，生成完整 SRT 后交给 ChatGPT。 | 可访问并已登录的 AI Studio 和 ChatGPT 网页。 |
| 浏览器内 Whisper | 在浏览器内转写，所得 SRT 再发送到 ChatGPT。 | 首次需下载模型，以及所选推理方式需要的浏览器与硬件条件。 |
| 自建转写服务 | 发送到你配置的服务，转写结果再交给 ChatGPT。 | 在设置中填写 API 地址及服务需要的 Token。 |

- 浏览器内转写只改变语音识别的位置，后续总结仍会把文字发送到 ChatGPT。
- 本地模型保存在此扩展的浏览器缓存中，不会自动与原版共享。

### 自定义整理方式

- ChatGPT 默认提示词用于深度理解和结构化总结，可以按需要改成课程笔记、论证梳理或操作步骤。
- AI Studio 默认提示词用于生成带绝对时间戳的完整 SRT，修改时请保留完成校验需要的格式和完成标记。
- 两组提示词可以分别保存和恢复默认，恢复某一组不会覆盖另一组。
- 弹窗还提供临时对话和后台打开选项，AI Studio 转写页按既有流程在后台打开。

### 音频大小与后台打开

- 设置页可单独保存/恢复音频参数，默认AAC 64 kbps、单声道，来源音轨目标64 kbps；优先保留完整口播和原声语言。
- 平台有多种完整音轨时优先选择较小来源；只有单一完整音轨时，压缩只能减少上传大小，不能声称下载量同步减少。
- 本机压缩检查全长，默认不变更采样率；原B站浏览器音轨流程继续选最小带宽，不强制改走本机。
- 同一821秒抖音样本由13,545,027字节压为6,799,130字节，时长差小于0.01秒；尚未比较转写准确率。
- “GPT后台打开”只控制最终GPT页面是否切到前台；AI Studio转写阶段始终后台打开，关闭弹窗后任务仍继续。
- 附件采用分块传输后一次提交，避免抖音现代路径重复携带base64音频并超过浏览器64 MiB消息限制；旧目标页脚本会提示重新从视频页发起。
- 隔离Edge已验证27/60 MiB附件逐字节一致和单次上传/Run；实际登录AI Studio与GPT接力仍待验收。

### 知行批注书库联动

- 已有总结提醒采用文字胶囊，默认折叠；胶囊与展开面板标题栏均可拖动，位置保存在当前浏览器，刷新后恢复，窗口缩小时限制在屏幕内；点击后逐条打开该视频已核实完成的总结，B站不同分P分别匹配。
- 视频进入全屏、网页全屏、影院或占据窗口的放大状态时，胶囊和列表全部隐藏；退出只恢复折叠入口，不弹出旧列表。
- 只读核验对应ChatGPT对话的完成且非空正式回复；保存链接、生成中或读取失败不计为完成。需要已登录ChatGPT及支持 `list-video-v1` 的书库；核验当前视频保存记录，不扫描全部历史、不保存正文/凭据、不发送新总结。
- 没有普通ChatGPT页时可短暂打开后台核验页；仅自动关闭扩展创建且从未被用户使用的页面。设置中可关闭“已有总结提醒”，书库联动块恢复默认不会清空数据。
- 在B站“稍后再看”、YouTube Watch later或抖音“稍后再看”播放页切换视频后，提醒按浏览器提供的当前标签页地址重新核验；不会把初次打开的旧地址当成当前视频，B站分P仍分别匹配。
- 多页候选显示核验进度并可继续核验；查询期间保留“正在核验已有总结”折叠入口，读取失败明确显示未知及刷新入口；核验入口可在ChatGPT页面资源尚未全部加载时就绪；跳过休眠页面，旧页不可用时只换一次后台入口，切回视频保留结果或具体失败提示。设计、源代码与日常加载验收分别见[已确认方案](设计对齐稿/已有总结提醒/2026-11-13%20已确认方案与实施.md)。

- 普通聊天默认自动保存视频链接、封面副本和对应的私人ChatGPT对话链接；只存信息卡片，不存总结正文、字幕或音频。
- 临时聊天默认关闭；已有明确保存的临时聊天选择仍保留，开启时完全不入书库。
- 需要同时更新知行批注书库扩展及其Native数据中心，书库新增视频类型和全部/有批注/无批注筛选；有划线或文字均算有批注，删掉最后批注不会删除视频卡片。
- 每个ChatGPT对话保留独立记录，同视频再次总结不会覆盖旧链接；相同对话的重试不重复建卡片。
- 发送确认并取得有效对话链接后建立记录，不据此宣称ChatGPT已完成生成；原对话访问权限仍取决于原账号，不创建公开分享链接。
- 设置页的书库联动块可单独开关、修改书库扩展ID、恢复本块默认、查看状态和重试；失败保留本地待办，不重发总结。封面缺失明确显示，待办保留以便后续补齐。
- 默认书库ID为`ajjcbhalcgpmelnmlnheefbfikdgmjdp`，适用于当前既有安装；其他安装可从扩展管理页复制实际ID。不开启额外常驻服务或历史扫描。
- 协议与保护边界见[设计原稿](设计对齐稿/视频总结与书库联动/2026-11-10%20视频总结自动入库.md)，实现与安装证据见[实施记录](docs/superpowers/plans/2026-11-10-video-library.md)；源码不代表日常浏览器已加载。

### 同时参考视频画面

- 开启“图片提取·开”后，本机程序会抽取画面并生成带时间戳的拼图。
- 默认按场景变化选帧，无有效候选或检测失败时回退到间隔截图，场景变化检测不理解画面语义。
- 默认间隔 5 秒，每张拼图最多 3 × 3 格，最多 15 张，即最多 135 个画面，末张可以不足九格。
- 视频较长、超出容量时会自动增大间隔以覆盖全程，因此拼图不能代替逐帧观看。
- 提取方式、间隔、拼图数量和画质等参数可以调整，并可单独恢复图片提取默认设置。
- 关闭图片后，不会为了截图下载视频或抽帧，但无字幕时仍可能下载必要音频或原视频。

### 查看进度与取消

- 在视频页或本任务的 AI Studio / ChatGPT 页重新打开扩展，可查看任务阶段并取消。
- 所有源视频页关闭后，也可在其他页面打开扩展查看当前队列；弹窗显示后台已接收后即可关页。
- 视频页不显示进度浮窗；提交后由后台读取信息和字幕，关闭弹窗或源视频标签页不会取消已接收的任务。
- B站、YouTube、抖音统一优先现成字幕，需要转写时默认 Groq；旧版分平台选择会在5.8.0首次运行迁移为统一 Groq，之后手动改选的服务继续保留，Groq失败不会自动切换Google。
- 多个视频从接单开始按顺序排队，Groq转写和 ChatGPT 总结依次处理，前一个视频的本次回复完成、失败或等待超时后再处理下一个；已发送的总结不会自动重发。
- 排队期间尽早固定作品信息和封面；B站字幕路径直接沿用已取得的封面，避免关页后再次查询失败造成缺图。
- ChatGPT 需要人工访问验证时，当前任务在原目标页等待，完成验证后自动继续，后续视频继续排队。
- 队列在本次浏览器运行期间维护；退出浏览器、重新加载或更新扩展会中断队列，任务进行中请避免这些操作。
- 来源切换或取消会触发相应防护，扩展不会把已判定失效的任务继续交接给 ChatGPT。

## 隐私与权限

- 提示词、图片设置和转写配置保存在此扩展的浏览器存储中，自建服务 Token 也保存在该存储中。
- 开启书库联动时，视频链接、封面副本和私人 ChatGPT 对话链接还会保存到本机知行批注书库，临时聊天不入库。
- 字幕、转写文本及所选图片会发送到 ChatGPT，Groq路径向Groq发送音频和Native读取的凭据，AI Studio 路径会向 Google 发送音频，自建路径会向配置的服务发送音频和认证信息。
- 本地 Whisper 首次下载模型需要访问模型分发服务，完成本地转写后仍按任务设置上传文字。
- 本机临时文件会在任务完成、取消或进程正常结束后清理，异常退出可能留下临时目录。
- 最近一次网页交接的阶段、版本、时间和任务标识保存在本地用于排障，该记录不含音频、提示词或账号凭据。
- 扩展没有开发者运营的数据收集服务器，各平台和 AI 服务分别适用自身的数据处理规则。

| 权限 | 用途 |
|---|---|
| `activeTab` / `tabs` | 识别当前视频、打开目标页并管理任务标签页。 |
| `storage` | 保存提示词、设置和任务诊断状态。 |
| `scripting` | 在已授权页面补载缺失的内容脚本。 |
| `offscreen` | 支持浏览器内转写处理。 |
| `nativeMessaging` | 与本机媒体程序通信。 |
| 站点访问权限 | 提取平台内容并向 AI 网页交接，自建服务按配置申请额外权限。 |

- 完整说明见 [PRIVACY_POLICY.md](PRIVACY_POLICY.md)，实际权限声明见 [manifest.json](manifest.json)。

## 常见问题

### 点击运行后为什么还没有总结？

- 无字幕视频需要先获取音频并转写，AI Studio 路径还要等待完整逐字稿通过校验。
- 重新打开扩展查看当前阶段，再检查对应网页是否登录、附件是否上传成功或生成是否截断。
- 上传或发送状态不明确时先查看目标页，避免重复点击产生相同任务。

### 为什么提示找不到本机程序？

- 先确认运行了本包安装脚本，再在设置页检测本机程序，排查和回退方法见 [INSTALL.md](INSTALL.md)。
- 旧测试程序若登记了不同的扩展 ID，需要使用本包脚本重新安装。

### 为什么有的视频提取失败？

- 平台要求登录、媒体地址失效或下载受限时可能失败，请先确认视频在浏览器中能正常播放。
- 扩展会留存有界本地诊断，Agent应先运行 `py -3 scripts/diagnostics.py --json` 自行读取，不要求用户复制控制台错误。

### 能否完全离线总结？

- 当前工作流依赖 ChatGPT 网页，浏览器内 Whisper 只负责本地转写，不能让整个总结流程离线运行。

## 开发与贡献

- 扩展采用 Manifest V3，界面和内容脚本使用 JavaScript / HTML / CSS，本机媒体程序使用 Python。
- 开发检查需要 Node.js 与 npm，浏览器测试使用 Playwright，Windows 打包使用 PowerShell。
- 本节仅供参与开发的用户，使用发布 ZIP 安装扩展时不需要执行。
- 如需修改源码，先克隆独立仓库，再安装开发依赖：

```powershell
git clone https://github.com/severin-ye/VidSift.git
cd VidSift
```

- 在包含 `package.json` 的 VidSift 目录执行：

```powershell
npm ci
npm run check

# 浏览器流程测试，使用隔离环境
npm run test:browser
npm run test:edge

# 本机程序测试，需要先准备 Python 依赖
python -m pip install -r requirements-native.txt
python -m unittest discover -s tests/native -v

# Windows：生成可解压加载的扩展 ZIP
npm run package
```

- `npm run check` 检查语法、扩展资源、版本一致性及 Node.js 测试，不代表真实登录网站流程已经通过。
- `npm run test:browser` 可通过 `VIDSIFT_BROWSER_EXE` 指定 Chromium，`npm run test:edge` 需要已安装 Edge。
- 设置 `VIDSIFT_ORIGINAL_EXTENSION` 指向原版 4.12.0 解压源码，可验证并存及设置隔离，测试不使用日常浏览器数据。
- `package.json` 是版本来源，修改版本后用 `npm run version:sync` 同步 manifest，打包结果输出到 `dist/`。
- `.task-artifacts/` 保存任务下载、隔离浏览器配置与验证证据，不进入 Git 或分发包。
- 欢迎提交 Issue 或 Pull Request，请说明复现步骤、预期和实际结果，并去除 Token、Cookie、私人视频等敏感信息。

| 目录或文件 | 职责 |
|---|---|
| `background.js` / `background-video.js` | 后台任务与视频处理流程。 |
| `popup.*` / `options.*` | 扩展弹窗与设置页。 |
| `*-content.js` | 视频平台与 AI 网页的内容脚本。 |
| `native/` / `installer/` | 本机媒体程序与 Windows 安装、回退脚本。 |
| `tests/` | 扩展逻辑、本机程序和浏览器流程测试。 |
| `scripts/` | 版本同步、资源检查与打包脚本。 |

### 一条命令发版（维护者）

```powershell
npm run release
```

- 在已经提交改动的 `main` 分支运行，版本以 `package.json` 为准；首次使用需要 GitHub CLI 已登录（`gh auth login`），或提供当前进程的 `GITHUB_TOKEN`。
- 脚本自动检查源码状态和版本标签、运行检查、生成并验证可重复 ZIP、推送当前代码和版本标签、上传 ZIP 与校验文件，再下载校验，成功后才删除更旧的安装 ZIP。
- 全部步骤在本地由脚本串联完成，不需要 Agent 逐项打包、上传或删除，也不依赖 GitHub Actions 的计费状态。
- 已存在的版本标签必须仍指向当前提交；脚本不会覆盖标签或强推，发布新改动前应正常增加版本并提交。
- 上传或校验失败时保留旧包，修复原因后重复运行同一命令即可继续，已验证的相同文件不会重复上传。
- 旧版只移除匹配 `VidSift-版本号-standalone.zip` 的安装包及其校验文件，保留标签、历史发布说明、其他附件和 GitHub 自动源码归档。
- 下载入口始终指向包含测试版的[最新版发布列表](https://github.com/severin-ye/VidSift/releases)，不需要手改 README 的版本下载链接。
- 如只想查看计划，可运行 `npm run release -- -DryRun`，该模式不会打包、推送或修改发布资产。
- 自动创建的版本默认标为测试版；本地脚本不会把既有版本强行改为稳定版。
