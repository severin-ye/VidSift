# GPT页总结切换与评分

在已收录视频的GPT对话页点击视频总结扩展，弹窗最上方可直接修改当前对话1～10分或选“未评分”清除；下面按每页10条显示同视频已保存的总结对话，点击后在原GPT标签页切换。评分和书库“全部对话”使用同一项持久数据，不改变主对话选择。

列表表示已收录对话，不证明GPT已生成完成；视频页原有完成核验提醒继续保持。普通及自定义GPT路由按同一对话UUID关联，B站分P分别匹配；临时聊天、未收录对话、关闭联动、旧书库和连接失败都有明确状态，未知评分不会显示成“未评分”。

书库是评分唯一所有者，沿用IndexedDB事务、durable outbox及原有Native共享；本次没有Native协议、数据库结构或数据迁移。浏览器桥接新增能力`summary-context-v1`和`rate-video-v1`，具体字段由书库`native/README.md`持有。弹窗每次动作读取真实活动标签，异步返回后复核原始URL；网页内容脚本不能调用评分入口。

状态审查覆盖初读、分页、评分保存/清除/失败、切页迟到结果、成员删除及来源拒绝。只确认成功回执后的本地保存；失败恢复最后确认分数，用户明确重试才再次请求。不会因切换或评分生成新总结或创建书库记录。

## 验证和边界

329项Node回归通过；两扩展、真实工具栏popup及IndexedDB在隔离Edge中验证直接评分、书库一致、清除及重开、12条分页、原标签切换、独立分数、自定义GPT路由、连接失败回退和未收录禁用。测试使用合成视频/对话，移除测试书库副本的Native权限；日常书库写入为0。旧测试夹具将popup作为普通标签页时被来源保护正确拒绝，已改为实际工具栏popup，未削弱产品校验。

自动化脚本为`tests/browser-gpt-summary-popup.cjs`，输入`VIDSIFT_LIBRARY_ROOT`指向已构建书库，可用`VIDSIFT_EXTENSION_ROOT`选择安装副本，`VIDSIFT_POPUP_EVIDENCE`指定本任务证据目录。每次关闭隔离浏览器并清理精确profile/receiver目录。源码、构建、安装文件和日常浏览器加载分别以任务回执核对，不把合成流程通过当作用户现场已生效。

资源边界：仅打开弹窗、选择分页、打分或切换时请求；每次外部调用最长6秒，查询每页10条，不读取正文、不新增轮询、常驻进程或第二份评分；已有发送任务状态轮询不受影响。

需求原稿见[GPT页评分与切换](../设计对齐稿/视频总结与书库联动/2026-11-14%20GPT页评分与切换.md)。Severin-skill功能目录不持有这两个独立产品，本次不修改其目录；现行数据与权限边界沿用两个产品正式来源。
